Задать вопрос на GitHub
Это безопасно для системы?
Да. Твики применяются через официальные API Windows, а перед первым изменением создаётся точка восстановления. Откатить можно отдельный твик или всю сессию.
Могут ли забанить в играх?
Нет. VOID TWEAKS не трогает файлы игр, не внедряется в процессы и не меняет их память — только настройки системы и реестра.
Windows пишет «Система Windows защитила ваш компьютер»
Это SmartScreen — он предупреждает о любых новых программах. Скачивайте установщик только с этой страницы или из GitHub Releases, нажмите «Подробнее» → «Выполнить в любом случае».
Нужен ли PRO для обычной оптимизации?
Нет. Твики, мониторинг, автозагрузка и встроенные утилиты бесплатны навсегда. PRO нужен для прерываний, GPU-разделов и раннего доступа.
Как оплатить и получить ключ?
Покупка доступна после входа в аккаунт: ключ привязывается к нему. Оплата через ЮKassa. После оплаты вы вернётесь на сайт, и ключ появится на странице — вставьте его в приложение. Вопросы — в GitHub Issues.
