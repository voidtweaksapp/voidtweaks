VOIDTWEAKS

Оптимизатор Windows 10/11 для геймеров. Написан на C#, распространяется бесплатно, PRO — разово и без подписки.

VOIDTWEAKS is a Windows 10/11 optimization utility for gamers. It disables telemetry and unnecessary services, applies safe system tweaks, and reverts every change in one click. Sign-in is optional and only needed to manage a PRO license.
