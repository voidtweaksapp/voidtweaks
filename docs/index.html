Меняет только параметры, которые реально поддерживает ваш драйвер: оффлоады, RSS, RSC, прерывания, буферы. Исходные значения — в nic-backup.json, Wake-on-LAN не трогается.

Game Mode включён, GameDVR и Xbox Game Bar выключены, оптимизации полноэкранного режима (FSO) отключены — меньше оверлеев и фоновой записи.
